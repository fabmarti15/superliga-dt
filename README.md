# Súper Liga — Donde tú eres el DT

Sitio del juego de mesa de fútbol chileno **Súper Liga · Donde tú eres el DT**, desarrollado por OGR Ltda.

Incluye el reglamento completo transcrito y el instructivo original en PDF, que hasta ahora no existía en internet.

- `index.html` — sitio de una sola página, sin dependencias.
- `reglamento-superliga.pdf` — instructivo original.
- `img/` — cartas e íconos extraídos del instructivo.

Créditos: juego desarrollado por OGR Ltda. · Ilustraciones y gráficas: Sebastián Alfaro · Diseño de caja: Pedro Chavarri.

## Publicar

En la carpeta del proyecto:

```bash
bash publicar.sh
```

Crea el repositorio, sube los archivos y activa GitHub Pages en
`https://<usuario>.github.io/superliga-dt/`. Requiere `gh` (`brew install gh`).
