# Súper Liga — Donde tú eres el DT

Sitio principal: https://superligadt.com/
Guía de regalos: https://superligadt.com/regalos-futboleros

## Publicación

Cloudflare Pages, proyecto `superligadt`, mediante carga directa de un ZIP con archivos públicos. Publicar solo `index.html`, `regalos-futboleros.html`, `404.html`, `robots.txt`, `sitemap.xml`, `_headers`, `_redirects`, el archivo público de verificación IndexNow, `reglamento-superliga.pdf` y las imágenes de `img/`.

GitHub es una copia del código; las páginas declaran el dominio propio como URL canónica. Para sincronizar este repositorio se utiliza exclusivamente el comando central `publica --sin-pages`.

## Estado comercial

Reimpresión en evaluación. El sitio recibe solicitudes de aviso por WhatsApp, sin cobros ni reservas. Precio, stock, edición y despacho deben confirmarse antes de ofrecer venta. No hay pasarela de pagos.

## Descubrimiento y medición

Texto accesible sin JavaScript, preguntas frecuentes, ficha contrastada con el reglamento histórico y datos estructurados Product, Organization y WebSite. No se publican ofertas, disponibilidad comercial ni reseñas sin confirmación. Un Product sin oferta o reseña puede no ser apto para resultados enriquecidos de Google.

Sitemap de las dos páginas principales, robots.txt y errores 404 reales. Las copias de Cloudflare Pages incluyen `noindex`; las páginas del dominio principal permiten indexación. El rastreo permitido no garantiza indexación ni recomendaciones.

Search Console: propiedad de dominio verificada. Cloudflare Web Analytics: activada mediante el hosting; cuenta visitas, no contactos ni ventas. Los enlaces WhatsApp incluyen la página de origen en el mensaje para atribución manual.

## Mantenimiento

Conservar el diseño y el reglamento. Verificar contenido, imágenes, enlaces y navegación en 320, 390 y 1440 px, además del contenido local sin JavaScript. No se ha probado un iPhone físico ni Safari.

Los respaldos, reportes, comprobantes y scripts de verificación se guardan en las carpetas locales excluidas por `.gitignore`. No incorporar contexto interno, cotizaciones, originales de imprenta ni datos de clientes al repositorio o al ZIP.
